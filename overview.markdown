# Visão Geral da Solução

Esta solução propõe a migração de um sistema legado para um modelo híbrido, integrando infraestrutura on-premises e Azure. Foca em:
- **Dimensionamento**: Recursos otimizados para 500 usuários concorrentes.
- **FinOps**: Estratégias para reduzir custos (ex.: Azure Reservations).
- **Automação**: Terraform e Ansible para IaC.
- **Resiliência**: Plano de Disaster Recovery e monitoramento.

Veja os detalhes em [Arquitetura](architecture.md).
